## 💳 Payment Processing Flow

### What Happens When Customer Pays:

```
1. Customer Visits Product Page
   ↓
2. Clicks "Buy Now" Button
   ↓
3. Redirected to Checkout Page (checkout-paystack.html)
   ↓
4. Sees Order Summary & Form
   ↓
5. Fills in Customer Information
   ↓
6. Clicks "Pay with Paystack" Button
   ↓
7. Paystack Secure Popup Opens
   ↓
8. Customer Chooses Payment Method:
   - 💳 Card (Visa, Mastercard, Verve)
   - 🏦 Bank Transfer
   - 📱 USSD Code
   - 🤖 QR Code
   ↓
9. Payment Processed by Paystack
   ↓
10. Backend Verifies with Paystack API (payment-verify.php)
   ↓
11. Order Status Updated
   ↓
12. Confirmation Email Sent to Customer
   ↓
13. Redirected to Success Page
   ↓
14. Customer Sees: ✅ Payment Confirmed!
```

## 🔑 Security Information

### Public Key (Safe to Share)
- Format: `pk_test_*` (testing) or `pk_live_*` (production)
- Location: Frontend code, configuration files
- Use: Initialize Paystack payment popup
- **Status**: ✅ In `paystack-config.js`

### Secret Key (KEEP PRIVATE)
- Format: `sk_test_*` (testing) or `sk_live_*` (production)
- Location: Backend only (payment-verify.php)
- Use: Verify payments on your server
- **⚠️ WARNING**: Never expose in frontend code, never commit to git

### Card Details
- **NOT stored** on your server
- **NOT seen** by your website
- **Handled securely** by Paystack
- **Encrypted** in transit using HTTPS

// Example of what it should look like:

// Currency Settings (₦ Nigerian Naira)

minAmount: 100,      // Minimum ₦100
maxAmount: 50000000  // Maximum ₦50,000,000

// Service Fee (added to every order)
serviceFee: 2500,    // ₦2,500

// Paystack Commission (automatic)
paystackCommission: 0.015  // 1.5% of amount

## 🎯 Implementation for Your Pages

### Add Payment to Product Pages

**Step 1**: Add script includes in your HTML `<head>`:
```html
<script src="https://js.paystack.co/v1/inline.js"></script>
<script src="paystack-config.js"></script>
<script src="paystack-handler.js"></script>
<script src="payment-handler.js"></script>
```

**Step 2**: Add buy button to product cards:
```html
<button 
    data-buy-now
    data-product-id="gift-frame-123"
    data-product-name="Beautiful Bedside Picture Frame"
    data-product-price="2500"
    data-category="gifts"
>
    Buy Now - ₦2,500
</button>
```

**Step 3**: When clicked, it automatically:
- Saves order to localStorage
- Redirects to checkout-paystack.html
- Shows order summary
- Takes payment
- Redirects to success/failure page

## 💬 Common Questions

**Q: Is my card information safe?**
A: Yes! Paystack never gives your card details to brainboxX. All card processing happens securely on Paystack's PCI-DSS Level 1 compliant servers.

**Q: What payment methods do you accept?**
A: We accept cards (Visa, Mastercard, Verve, AmEx), bank transfers, USSD codes, and QR codes - all automatically through Paystack.

**Q: Will I be charged for testing?**
A: No! Test payments using the test cards provided don't charge any real money.

**Q: How long does payment take?**
A: Most payments process instantly. Bank transfers may take 1-2 hours.

**Q: What if my payment fails?**
A: You can safely retry with a different payment method. Your account is not charged if payment fails.
