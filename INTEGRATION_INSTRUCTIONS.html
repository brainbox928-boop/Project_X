💻 Option 3: Add to Your Existing Pages (10 minutes)

📋 Step 1: Add Scripts to Your Page HEAD

Open your product page (e.g., brainboxtools.html) and add these lines in the <head> section:

<script src="paystack-config.js"></script> <script src="paystack-handler.js"></script> <script src="https://js.paystack.co/v1/inline.js"></script>

🛒 Step 2: Add "Buy Now" Button to Each Product

Replace your product buttons with this:

<button class="primary-btn" onclick="addToCheckout('Product Name', 15000)"> Pay with Paystack - ₦15,000 </button>

Example for your courses:

<!-- Web Development Bootcamp --> <button class="primary-btn" onclick="addToCheckout('Web Development Bootcamp', 10000)"> Pay Now ₦10,000 </button> <!-- AI Tools Mastery --> <button class="primary-btn" onclick="addToCheckout('AI Tools Mastery', 15000)"> Pay Now ₦15,000 </button>

⚙️ Step 3: Add JavaScript Function

Add this script to the bottom of your page (before closing </body>):

<script> function addToCheckout(productName, price) { // Create order object const order = { items: [ { id: Date.now(), name: productName, price: price, quantity: 1 } ], total: price, timestamp: new Date().toISOString() }; // Save to browser storage localStorage.setItem('brainboxX-pending-order', JSON.stringify(order)); // Open checkout page window.location.href = 'checkout-paystack.html'; } </script>
✅ That's it! Your products are now connected to Paystack. When customers click "Pay Now", they'll be taken to checkout.

🚀 Deployment to Server

Step 1: Upload to Web Server

Log into your hosting cPanel or FTP:

  • Upload payment-verify.php to public_html/
  • Upload all .html and .js files to public_html/
  • Set permissions: payment-verify.php to 644

Step 2: Update File Path in Checkout

In checkout-paystack.html, find this line:

const verificationUrl = 'payment-verify.php';

Change to:

const verificationUrl = 'https://yourwebsite.com/payment-verify.php';
✅ Verification: Test by visiting https://yourwebsite.com/payment-verify.php - should show error message (good sign!)

🆘 Quick Help

I see a blank page or error?

1. Press F12 to open Developer Tools

2. Click Console tab

3. Look for red error messages

4. Make sure all .js files are in same folder as .html files

Payment button doesn't work?

1. Verify Paystack scripts loaded: F12 → Network tab

2. Check public key is correct in paystack-config.js

3. Ensure 'onclick' attributes are properly formatted
