## 🔧 TECHNICAL DETAILS

### **Architecture**
```
Customer → Your Website → Paystack Popup → Paystack Server
                                             ↓
                          ← Payment Confirmation + Reference
                          ↓
                      Your Backend Verification
                          ↓
                      Database/Email Notification
                          ↓
                    Success Page to Customer
```

### **Data Flow**
1. Customer clicks "Pay Now"
2. Order stored in browser localStorage
3. Checkout page retrieves order data
4. Paystack popup opens
5. Customer enters payment details (to Paystack, not your server)
6. Payment processed securely
7. Reference sent back to your site
8. Backend verifies with Paystack using secret key
9. Order confirmed
10. Success page displays

### **API Key Strategy**
- **Public Key** (Safe for frontend): Used in paystack-config.js, initialization only
- **Secret Key** (Keep private): Used in payment-verify.php, backend only
- **Zero card data** on your server: All handled by Paystack PCI DSS Level 1

## 🆘 TROUBLESHOOTING

### "Paystack is not defined"
```
✓ Ensure paystack-config.js loads before paystack-handler.js
✓ Check script tags in correct order
✓ Verify files in same folder as HTML pages
```

### "Order not showing in checkout"
```
✓ Use paystack-quick-test.html to start fresh
✓ Check browser console (F12) for errors
✓ Clear localStorage: localStorage.clear()
✓ Reload page and try again
```

### "Payment button doesn't work"
```
✓ Open browser console (F12 → Console)
✓ Look for error messages in red
✓ Verify public key in paystack-config.js
✓ Check Paystack account has test mode enabled
```

### "Backend verification failing"
```
✓ Verify payment-verify.php uploaded to server
✓ Check file permissions (644)
✓ Verify secret key in payment-verify.php matches
✓ Ensure cURL enabled on server
✓ Check server error logs
```
