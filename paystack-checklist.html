📋 Phase 1: Account Setup
⚠️ You must have a Paystack account to proceed with payment integration.
  • Create Paystack Account
    Visit https://paystack.com and sign up for a free account. Takes about 5 minutes.
  • Verify Email Address
    Check your email and click the verification link from Paystack.
  • Complete KYC (Business Info)
    Fill in your business name, type, phone, and address in the Paystack dashboard.
🔑 Phase 2: Get Your API Keys
ℹ️ API Keys are unique codes that connect your website to Paystack. You'll need the Public Key (safe) and Secret Key (keep private).
  • Go to Paystack Dashboard
    Navigate to https://dashboard.paystack.com and log in with your account.
  • Find API Keys Section
    Click Settings (⚙️) → Developers → API Keys
  • Copy Test Public Key
    Find the key starting with "pk_test_" and copy it. This is what you'll use for testing.
  • Copy Test Secret Key
    Find the key starting with "sk_test_" and save it safely. KEEP THIS PRIVATE - never share or commit to git!
⚙️ Phase 3: Configuration
✅ All required files have been created. Now just add your keys!
  • Open paystack-config.js
    Open the file "paystack-config.js" in your code editor.
  • Find Line 11 (Public Key)
    Look for:
    publicKey: 'pk_test_YOUR_PUBLIC_KEY_HERE'
  • Replace with Your Public Key
    Replace 'pk_test_YOUR_PUBLIC_KEY_HERE' with your actual public key.
    publicKey: 'pk_test_4a7f7k2x9c1b8d5e'
  • Save paystack-config.js
    Save the file. Your configuration is now updated!
🧪 Phase 4: Test Payment
⚠️ Use the test cards below - they're safe and won't charge any real money!
  • Open checkout-paystack.html
    Open the file "checkout-paystack.html" in your web browser.
  • Fill Customer Information
    Enter test details:
    Name: Test Customer Email: test@example.com Phone: +234 801 234 5678 Address: Test Address
  • Click "Pay with Paystack"
    Click the yellow payment button to open Paystack popup.
  • Use Test Card (Success)
    Card Number: 4084084084084081
    Expiry: 12/25 (any future date)
    CVV: 123 (any 3 digits)
    OTP: 123456
  • Verify Success Page
    After payment, you should see the success page showing your payment reference and amount.
🖥️ Phase 5: Backend Setup (Production Ready)
ℹ️ This ensures payments are verified securely on your server. Required before going live!
  • Upload payment-verify.php to Server
    Upload the "payment-verify.php" file to your web server's root directory.
  • Update Secret Key in payment-verify.php
    Open payment-verify.php on your server and replace the secret key on line 19:
    $PAYSTACK_SECRET_KEY = 'sk_test_YOUR_SECRET_KEY_HERE';
  • Set Up Database for Orders
    Create a database table to store orders. Update payment-verify.php to insert order data after payment verification.
🚀 Phase 6: Going Live
✅ You're ready for production! These steps prepare you for real payments.
  • Request Paystack Live Account Activation
    Go to your Paystack dashboard and follow prompts to activate your live account. You'll need to provide business documents. Approval typically takes 2-3 days.
  • Update Keys with Live Keys
    Once approved, Paystack will give you live keys (pk_live_* and sk_live_*). Update both paystack-config.js (frontend) and payment-verify.php (backend) with these live keys.
